# 생성된 이미지 액션 컴포넌트 기능명세서

## 1. 개요

`GeneratedImageActions` 컴포넌트는 AI로 생성된 이미지에 대한 사용자 액션을 제공하는 UI 컴포넌트입니다. 사용자가 생성된 이미지를 갤러리에 저장하거나, 공유하거나, 로컬 기기에 다운로드할 수 있는 기능을 제공합니다.

## 2. 컴포넌트 구조

```tsx
export default function GeneratedImageActions({ imageUrl, onSave }: IGeneratedImageActions) {
  // 구현 내용
}
```

### 2.1 Props

| 속성명 | 타입 | 필수 여부 | 설명 |
|--------|------|-----------|------|
| imageUrl | string | 선택 | 생성된 이미지의 URL |
| onSave | () => Promise<void> | 필수 | 이미지를 갤러리에 저장하는 함수 |

## 3. 주요 기능

### 3.1 갤러리 저장 기능

- 사용자가 생성된 이미지를 개인 갤러리에 저장할 수 있습니다.
- 부모 컴포넌트에서 전달받은 `onSave` 함수를 호출하여 저장 로직을 실행합니다.
- 저장 성공/실패 시 적절한 토스트 메시지를 표시합니다.

### 3.2 공유 기능

- 사용자가 생성된 이미지를 다른 사람과 공유할 수 있습니다.
- 현재는 개발 중인 기능으로, 준비 중 안내 메시지를 표시합니다.
- 향후 소셜 미디어 공유, 링크 복사 등의 기능이 추가될 예정입니다.

### 3.3 다운로드 기능

- 사용자가 생성된 이미지를 로컬 기기에 다운로드할 수 있습니다.
- 브라우저의 Blob API를 사용하여 이미지를 다운로드합니다.
- 다운로드 파일명은 `generated-image-{timestamp}.jpg` 형식으로 생성됩니다.
- 다운로드 성공/실패 시 적절한 토스트 메시지를 표시합니다.

## 4. 사용자 인터페이스

- 각 기능은 직관적인 아이콘과 텍스트로 구성된 버튼으로 제공됩니다.
- 갤러리 저장: Save 아이콘 + "갤러리에 저장" 텍스트
- 공유: Share2 아이콘 + "공유" 텍스트
- 다운로드: Download 아이콘 + "다운로드" 텍스트
- 이미지 URL이 없는 경우 모든 버튼은 비활성화됩니다.

## 5. 에러 처리

- 각 기능 실행 중 발생할 수 있는 오류를 try-catch 블록으로 처리합니다.
- 오류 발생 시 콘솔에 오류 내용을 기록하고, 사용자에게 적절한 오류 메시지를 토스트로 표시합니다.
- 이미지 URL이 없는 경우 기능 실행을 방지합니다.

## 6. 향후 개선 사항

- 공유 기능 구현: 소셜 미디어 공유, 링크 복사 등
- 이미지 포맷 선택 옵션 추가: JPG, PNG, WebP 등
- 이미지 해상도 선택 옵션 추가
- 이미지 편집 기능 연동: 크롭, 필터 등

## 7. 의존성

- @/components/ui/button: 버튼 UI 컴포넌트
- lucide-react: 아이콘 컴포넌트 (Save, Share2, Download)
- sonner: 토스트 메시지 표시 라이브러리
- @/types: 타입 정의 (IGeneratedImageActions)
